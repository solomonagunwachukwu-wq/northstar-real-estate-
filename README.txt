# Northstar Properties — Luxury Real Estate Website

A responsive, editorial-grade real estate web application built with semantic **HTML5**, modern **CSS3**, and **Vanilla JavaScript**.

> **Portfolio Demonstration Notice:** Northstar Properties is an illustrative luxury real estate brand created by **Solomon Agunwachukwu** as a front-end engineering and UI/UX showcase. All property listings, valuations, and client testimonials are sample content for demonstration purposes.

---

## Features

- **Editorial Luxury Design System:** Crafted with a deep forest green (`#112A22`), warm cream (`#F8F6F0`), crisp white, and muted antique gold (`#C5A059`) palette paired with *Cormorant Garamond* and *Plus Jakarta Sans* typography.
- **Interactive Property Search & Multi-Criteria Filtering:** Filter listings dynamically by listing category (*For Sale*, *For Lease*), location, architectural property type, and maximum budget.
- **Persistent Saved Shortlist:** Save and manage favourite residences using browser `localStorage` with an interactive shortlist modal.
- **Residence Detail Modals:** Inspect full architectural descriptions, specifications, and pre-fill an enquiry directly from any property card.
- **Accessible Contact & Enquiry Form:** Client-side form validation with clear inline error messaging and submission feedback.
- **Responsive Mobile-First Architecture:** Adapts cleanly across desktop, tablet, and mobile viewports with a collapsible mobile navigation drawer.

## Running Locally

No build tools or package installations are required:

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (or launch with the VS Code **Live Server** extension).
